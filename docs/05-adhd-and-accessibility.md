# ADHD, dyslexia & accessibility

ADHD brains thrive on **novelty, quick feedback and clear next steps**, and struggle with walls of text and invisible progress. Dyslexic readers benefit from clear fonts, spacing and hearing text. Life Sciences adds its own barrier: dense, labelled diagrams and a huge vocabulary. LifeMzansi builds support for all of this in – and every setting is in the **Preferences** panel.

| Feature | What it does |
|---|---|
| One step at a time | Lessons show one chunk with a clear Next button and a progress bar. |
| Focus mode | Hides navigation so only the lesson is on screen. |
| Focus sprints | A 5/10/15/25-minute timer with movement breaks. |
| Read aloud | Every lesson chunk and every diagram part can be read aloud (South African English voice where available). |
| Tappable diagrams | One part at a time: tap a part to see its name and function; the list of parts works as buttons too; letters can be hidden. |
| Fonts | Inter, Atkinson Hyperlegible or OpenDyslexic; adjustable size and line spacing. |
| Reading ruler | A band that follows the pointer to help keep your place. |
| Word anchors | Bolds the start of each word to guide the eye. |
| Calm mode | Switches off decorative animation and slows the labs (also follows the OS "reduce motion" setting). |
| High contrast | Pure black and white with thick focus rings. |
| Tap alternatives | Every sort, match and sequence activity works with taps and the keyboard – no dragging needed. |
| Base keypad | DNA and RNA answers can be entered with big coloured A, T, U, C, G keys. |
| Extra time | Mock papers offer +25% extra time or untimed practice. |

## Inclusive by design

- Labs never start moving until the learner presses a button, and each has an *Explain* box in plain language.
- Colour is never the only signal: diagrams use letters, buttons use text, and correct/incorrect states use icons as well as colour.
- Feedback is framed as "Not yet", never as failure, and effort earns XP and badges.
- Memory hooks (pink callouts) give mnemonics for lists such as the phyla and base pairing.
